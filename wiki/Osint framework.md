# Osint framework

## 🎯 Sintesi Strategica

L'**OSINT Framework** (nella sua incarnazione storica all'indirizzo *osintframework.com*) è una directory web interattiva, strutturata a mappa mentale (Mind Map), che funge da indice enciclopedico per la categorizzazione degli strumenti e delle fonti d'intelligence open-source. Non esegue indagini in autonomia, ma guida l'analista neo-formatosi (o sotto stress) nel processo logico di selezione dello strumento corretto in base all'input iniziale (Es. "Ho un indirizzo Email, quali tool posso usare?").

## 📚 Contesto e Definizioni

La sua importanza risiede nella tassonomia investigativa. Divide l'immenso (e caotico) mare dei tool in macro-categorie logiche: *Username*, *Email*, *Indirizzi IP*, *Dark Web*, *Trasporti*, *Dating Apps*. Quando un'indagine arriva a un punto morto (Dead End), il Framework suggerisce percorsi laterali che l'investigatore potrebbe aver dimenticato a causa del [[Bias cognitivo]].

## 📊 Dati, Tecnologie e Metriche

Il paradosso del Framework è la sua natura intrinsecamente effimera (Link Rot). A causa delle restrizioni API imposte dal [[Capitalismo delle piattaforme]] e della chiusura improvvisa dei tool gratuiti da parte degli sviluppatori indipendenti, il 30-40% dei link elencati nelle directory OSINT smette di funzionare ogni anno. Le unità d'intelligence strutturate abbandonano presto i framework pubblici per costruire directory chiuse (Wiki interne) costantemente manutenute da protocolli di validazione.
