# Osint nel sistema di sicurezza nazionale – dis

## 🎯 Sintesi Strategica

L'**OSINT nel Sistema di Sicurezza Nazionale (DIS - Italia)** rappresenta l'integrazione strutturale delle Fonti Aperte all'interno dell'architettura di intelligence governativa italiana. Se storicamente l'intelligence si basava sul segreto (Spionaggio Umano - HUMINT), oggi il Dipartimento delle Informazioni per la Sicurezza (DIS) e le agenzie collegate (AISI, AISE) considerano l'OSINT il layer informativo primario, indispensabile per contestualizzare minacce ibride, infiltrazioni economiche e campagne di [[Disinformazione]] straniera.

## 📚 Contesto e Definizioni

Il DIS coordina la ricerca informativa tra agenzie. L'uso dell'OSINT governativo si concentra su:
1.  **Monitoraggio della Propaganda:** Identificazione precoce di network di [[Botnet]] o narrative ostili sui social network ([[Socmint]]) volte a manipolare l'opinione pubblica nazionale.
2.  **Protezione del Patrimonio Economico:** Analisi tramite [[Finint]] (es. incrocio di database camerali pubblici internazionali) per scovare acquisizioni ostili di aziende strategiche italiane (Golden Power) da parte di fondi ombra legati a nazioni avversarie.
3.  **Antiterrorismo e Geopolitica:** Mappatura dei network criminali stranieri prima che questi operino sul territorio nazionale.

## 📊 Dati, Tecnologie e Metriche

Il salto qualitativo recente è la transizione verso la [[Data driven intelligence]]. Il sistema di sicurezza non usa più analisti manuali per leggere i giornali; utilizza cluster di server protetti per l'ingestione massiva ([[Data lake]]) di tutto il traffico open-source del Mediterraneo Allargato, applicando modelli di [[Machine learning]] e traduttori [[Llm]] sovrani (Air-Gapped) per processare petabyte di dati arabi, russi e cinesi in tempo reale, estraendo pattern di rischio matematici.
