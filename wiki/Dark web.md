# Dark web

## 🎯 Sintesi Strategica

Il **Dark Web (Rete Oscura)** è un minuscolo sotto-insieme del [[Deep web]] che è stato intenzionalmente nascosto e richiede software, configurazioni o autorizzazioni specifiche per essere accessibile. Si basa sull'architettura delle Darknet (reti overlay peer-to-peer, la più famosa è [[Tor]]), progettate per garantire il totale anonimato sia agli utenti che navigano, sia ai server che ospitano i contenuti (Hidden Services).

## 📚 Contesto e Definizioni

Se il Clear Web usa i domini `.com` e `.it`, il Dark Web di Tor utilizza i domini `.onion` (lunghe stringhe crittografiche come `expyuz5...onion`). Non essendo indicizzato, non esiste un motore di ricerca centrale. L'accesso avviene tramite elenchi di link (es. Hidden Wiki) curati dalla comunità. Questa architettura offre rifugio a whistleblower, dissidenti in regimi dittatoriali, ma anche, in maniera preponderante, ai mercati neri (Darknet Markets - DNM).

## 📊 Dati, Tecnologie e Metriche

I Threat Actor utilizzano il Dark Web come centro logistico per il Cybercrime-as-a-Service: vendita di database rubati, traffico di armi, droga e commissioni per attacchi [[Ransomware]]. Tutte le transazioni avvengono tramite criptovalute, prediligendo [[Monero]] a causa dell'opacità garantita. La [[Cyber threat intelligence]] esegue [[Scraping]] continuo sui forum hacker (es. Exploit.in, Breachforums) nel Dark Web per identificare minacce prima che vengano lanciate contro bersagli istituzionali, ma l'operazione richiede massiccia [[Opsec]] e l'uso di [[Macchina virtuale]] effimere.
